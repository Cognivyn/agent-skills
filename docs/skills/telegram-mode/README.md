# `telegram-mode`

Compresses assistant prose into concise (`lite`) or Telegram-style (`full`)
English to cut output tokens and latency while keeping code, file paths,
commands, and negations exact.

- Authoritative workflow: [`SKILL.md`](../../../telegram-mode/SKILL.md)
- Prompt shorthand guide: [`prompt-shorthand.md`](../../../telegram-mode/references/prompt-shorthand.md)

## When to use

- Internal coding, debugging, code review, and subagent handoff turns.
- Switch to `off` for client-facing docs, PR descriptions, or compliance text.
