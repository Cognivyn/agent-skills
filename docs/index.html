Discovery Contract Architecture

How Agent Discovery Works

Agent clients (such as Kilo or Claude Code) scan configured skills directories for folders containing a valid SKILL.md.

  • YAML Frontmatter Trigger: The name and description declare exactly when an agent invokes the skill.
  • Self-Contained Isolation: Package assets like scripts or templates stay inside top-level skill folders.
  • Zero External Dependencies: Built with Python standard library only for max portability across environments.
git-clean/SKILL.md
---
name: git-clean
description: >
  Safely synchronize a local main branch with origin
  without losing local work or running git reset --hard.
metadata:
  dependencies: []
---

# Workflow
1. Check for uncommitted local changes.
2. Fetch latest updates from origin.
3. Safely rebase or fast-forward...

Dependency-Free CLI Management

Manage agent skills with the lightweight Python standard library CLI tool.

Initializes local workspace config and creates the target skills directory (defaults to $HOME/.agents/skills).

$ ./agent-skills init

Lists repository skills and labels each local skill as available or added alongside tracking remote branch status.

$ ./agent-skills list

Verifies YAML frontmatter, validates skill folder name parity, and detects missing dependencies or circular dependency chains.

$ ./agent-skills validate

Validates and copies (or symlinks with --link) skills directly into your agent client's skills directory.

$ ./agent-skills add git-clean gh-issue-create --link

Safely removes manifest-managed skills without touching unmanaged external skill directories.

$ ./agent-skills remove git-clean

Safety & Reliability Guarantees

Built with engineering discipline so agent execution remains predictable and safe.

Non-Destructive Workflows

Skills like git-clean never perform hard resets or clean uncommitted files without explicit user intervention.

Dependency Cycle Check

Validation engine continuously checks frontmatter dependencies to eliminate circular deadlocks before addition.

Companion Documentation

Every skill maintains both an agent workflow (SKILL.md) and a human companion guide under docs/skills/.
